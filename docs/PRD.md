## 1. 개요

### 1.1 한 줄 요약

4×4 **부분 마방진**(빈칸 2개, 1~16, 마법 상수 34)을 완성할 때, **제출 전** 10개 줄(행4·열4·대각선2)의 합을 빠짐없이 검증하여 채점 실패 후 장시간(15~20분) 우연 탐색을 줄인다.

### 1.2 Mom Test — 진짜 vs 표면

| 구분 | 내용 |
|------|------|
| **진짜 문제** | 조건을 알고 있어도 제출 직전 검증(특히 **대각선 2개**)을 빠뜨리고, 채점/TA 피드백 후 긴 시간을 들여 우연히 누락을 찾아야 함 |
| **표면 문제 (Non-Goals)** | Solver·전체 ECB·GridUI·자동 채우기·백트래킹 완성 탐색 |

### 1.3 증거 (요구사항 우선순위 근거)

1. 채점 실패 후 누락 찾기 **~20분**
2. 행·열 확인 후 **대각선 한쪽만** (또는 미검증)
3. 체계적 재검증이 아닌 **우연 발견**

## 2. 도메인

| 항목 | 규칙 |
|------|------|
| 격자 | 4×4 |
| 값 | **0** = 빈칸; 그 외 **1~16** (중복 없음 — 완성 시) |
| 마법 상수 | **34** (4×4 표준: `4×(16+1)/2`) |
| 유효 줄 | **10개** — 행 4 + 열 4 + 주대각선(↘) + 반대대각선(↙) |
| 이번 스코프 | 빈칸 **2개** 채운 **부분** 격자의 **검증** (자동 풀이 아님) |

### 2.1 예시 격자 (교육용)

```
16   3   2  13
 5  10  11   ?
 9   6   ?  12
 4  15  14   1
```

빈칸 2개 — 후보 값은 1~16 중 미사용 수 (Solver 스코프 외).

### 4.1 Goals (Must)

| ID | Goal |
|----|------|
| G1 | 제출(또는 TA 전달) **전** 10줄 합 34 검증 |

## 5. R-G-I-O

| | |
|---|---|
| **Role** | 학습자 — 완성 격자에 대한 **판정 책임** |
| **Goal** | 외부 채점 **전** 스스로 “통과/실패 + 틀린 줄” 확정 |
| **Input** | 4×4 정수 격자 (0 허용), 파일 또는 인라인 |
| **Output** | 10줄별 합; `PASS` / `FAIL`; FAIL 시 줄 ID 목록 (예: `ROW_2`, `DIAG_MAIN`) |

## 6. 기능 요구사항 (MVP — 검증)

### FR-1: 줄 합 계산

- 행 4, 열 4, ↘, ↙ 각각 합 산출
- 0 포함 줄은 “완성” 판정과 별도 — **부분 검증 모드** 허용 (0이 있으면 `INCOMPLETE` 플래그)

### FR-2: 판정

- 10줄 모두 34 → `PASS` (0 없을 때만 `COMPLETE_PASS`)
- 하나라도 ≠34 → `FAIL` + 줄 목록
- 0 존재 → `INCOMPLETE` (합 계산은 수행)

### FR-3: CLI (Command)

| 명령 | 설명 |
|------|------|
| `validate` | 격자 입력 → FR-1, FR-2 |
| `checklist` | 10줄 체크리스트 출력 |
| `test` | 자동 테스트 실행 |

### FR-4: 테스트 (Test Loop)

| ID | 시나리오 | 기대 |
|----|----------|------|
| T1 | 행·열 34, ↘ **36** | `FAIL`, 대각선 식별 |
| T2 | 시뮬레이션/교재 정답 배치 (7·8 올바른 위치) | `PASS` |
| T3 | 빈칸(0) 포함 | `INCOMPLETE` |

## 8. Rule (비즈니스 규칙)

| ID | Rule |
|----|------|
| BR-1 | 셀 ∈ {0} ∪ [1, 16] |
| BR-2 | 완성 시 1~16 각 1회 |
| BR-3 | 10줄 합 = 34 |
| BR-4 | 제출 전 체크리스트 10항목 필수 |
| BR-5 | `FAIL` 시 수정 제안은 **2차** — 1차는 **줄 식별만** (Mom Test: 솔루션 먼저 금지) |
