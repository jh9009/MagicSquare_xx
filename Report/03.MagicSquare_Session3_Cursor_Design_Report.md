## 3. Rule — `.cursorrules` 요약

| 항목 | 규칙 |
|------|------|
| 도메인 | 4×4, `0`×2, 1~16, 합 **34** |
| 출력 | `int[6]` `[r1,c1,n1,r2,c2,n2]`, **1-index** |
| SSOT | MagicConstant (`34`/`16` 리터럴 산재 금지) |
| ECB | `boundary → control → entity`, entity `→ *` import 금지 |
| 오류 | E001~E007 boundary; entity E001~E005 **금지** |
| Dual-Track | Logic: Domain Mock 금지 / UI: Mock 허용 |
| 테스트 | `D-*` / `U-*`, `test_d_*` / `test_u_*` |
| TDD | RED→GREEN→REFACTOR; skip/xfail/assert 완화 금지 |
| 선언 | `Phase \| Layer \| Track` |
| git | commit/push — **사용자 요청 시만** |
| 체크리스트 | `R1–R4 \| C1–C4 \| ↘ ↙` |

전문: `.cursorrules` (73줄).
